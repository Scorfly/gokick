## Create Ad Break

Starts an ad break on the authenticated broadcaster's channel. Requires the `ads:write` scope.

`break_duration_seconds` must be between 7 and 90. `id` is a UUID generated by your app and used to identify the break. Kick responds with `202 Accepted`.

```go
	client, _ := gokick.NewClient(&gokick.ClientOptions{
		UserAccessToken: "xxxx",
	})

	response, err := client.CreateAdBreak(context.Background(), gokick.CreateAdBreakRequest{
		BreakDurationSeconds: 30,
		ID:                   "123e4567-e89b-12d3-a456-426614174000",
	})
	if err != nil {
		var kickErr gokick.Error
		if errors.As(err, &kickErr) && kickErr.Description() != "" {
			code, parseErr := gokick.NewAdBreakErrorCode(kickErr.Description())
			if parseErr == nil {
				log.Fatalf("ad break rejected: %s (%s)", code, kickErr.Message())
			}
		}
		log.Fatalf("Failed to create ad break: %v", err)
	}

	spew.Dump("response", response)
```
output
```

(gokick.Response[gokick.AdBreakResponse]) {
 Result: (gokick.AdBreakResponse) {
  AdBreakID: (string) (len=12) "Xq3LmP9aB2cD",
  ID: (string) (len=36) "123e4567-e89b-12d3-a456-426614174000",
  RemainingAdBreaks: (int) 2

```

Kick returns one of these codes in `Error.Description` when the break is rejected (`400`, `409`, or `429`):

- `CHANNEL_IS_NOT_LIVE`
- `CHANNEL_NOT_OPTED_IN`
- `ADS_BLOCKED`
- `ADS_RESTRICTED`
- `AD_BREAK_ACTIVE`
- `MAX_AD_BREAKS_REACHED`
- `AUTO_ADS_ACTIVE`

## Get Ad Break Status

Returns ad settings and recent ad breaks for the authenticated broadcaster's channel. Requires the `ads:read` or `ads:write` scope.

`ad_break_id` is omitted until Kick accepts the break.

```go
	client, _ := gokick.NewClient(&gokick.ClientOptions{
		UserAccessToken: "xxxx",
	})

	response, err := client.GetAdBreakStatus(context.Background())
	if err != nil {
		log.Fatalf("Failed to get ad break status: %v", err)
	}

	spew.Dump("response", response)
```

## Enroll in Ads

Enrolls the authenticated broadcaster's channel in ads. Requires the `ads:write` scope. Kick responds with `200 OK` and an empty payload.

```go
	client, _ := gokick.NewClient(&gokick.ClientOptions{
		UserAccessToken: "xxxx",
	})

	response, err := client.EnrollInAds(context.Background())
	if err != nil {
		var kickErr gokick.Error
		if errors.As(err, &kickErr) && kickErr.Description() != "" {
			code, parseErr := gokick.NewAdsEnrollErrorCode(kickErr.Description())
			if parseErr == nil {
				log.Fatalf("ads enrollment rejected: %s (%s)", code, kickErr.Message())
			}
		}
		log.Fatalf("Failed to enroll in ads: %v", err)
	}

	spew.Dump("response", response)
```
output
```
(string) (len=8) "response"
(gokick.EmptyResponse) {
}
```

Kick returns one of these codes in `Error.Description` when enrollment is rejected (`400` or `404`):

- `CHANNEL_NOT_FOUND`
- `CHANNEL_IS_LIVE`
- `CHANNEL_NEVER_STREAMED`
